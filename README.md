Repositório SmartAgenda:
- Em fase de desenvolvimento;
- Uso de Apache NetBeans IDE 14 e banco de dados MySQL;
- Desenvolvido por Júlia dos Anjos Cordeiro Silva com auxílio dos tutores;
- Está sendo desenvolvido com objetivo de realizar cadastro e listagem de agendamentos de alunos vinculados a uma instituição de ensino(escola, faculdade), visando facilitar a administração desses agendamentos;
- Serão realizados os cadastros de aluno, de responsável, de funcionário, o cadastro de agendamentos e a listagem desses agendamentos. Para utilização desse sistema é necessário o login no sistema, contando com uma interface intuitiva e acessível
